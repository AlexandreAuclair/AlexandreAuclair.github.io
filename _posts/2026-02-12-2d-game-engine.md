Voici un aperçu de mon projet **GauntletClone**, développé à l’Université de Sherbrooke durant l’automne 2023.  
Ce projet est conçu comme un jeu vidéo prototype pour le cours IFT215 où j'ai utilisé le temps donné pour faire une application avec interface utilisateur pour faire ce jeu.

**Code source:**  
[github.com/AlexandreAuclair/2D-game-engine](https://github.com/AlexandreAuclair/2D-game-engine)

---

## Résumé du projet

pour mon cours IFT215 de l'université de Sherbrooke j'ai fait ce jeu qui est un game engine qui utilise les maps créer sur Tilemap et qui utilise un parser de fichier XML pour lire les maps.
J'ai aussi fait mon propre game engine pour commencer le jeu et donc j'ai implémenté toute les mathématiques de formes vectorielles moi même.
J'avais aussi implémenter tout les call de SDL2 par moi-même pour les graphiques 2D et autres textures. Mon plus gros problème était que j'avais utiliser le système de class orienté objet de C++ qui n'était pas idéale.
---

## Technologies utilisées

- **C++** — code source  
- **SDL2** — call pour windows
- **SDL2_images** — gérer les textures
- **Tilemap** — gestion de map pour développement game dev

## Ce que j’ai appris

Ce projet m’a permis de :
- Comprendre comment faire un jeu avec C++ sur windows
- Structurer un projet C++
- Travailler avec SDL2 et C++
- Mettre en place une architecture modulaire et réutilisable


J'ai aussi compris comment le modèle orienté objet étais fragile. C'est pourquoi que dans mon prochain projet que j'ai fait de similaire j'ai pris une autre aproche.
