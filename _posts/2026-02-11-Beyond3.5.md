Voici un aperçu de mon projet **Beyond3.5**, développé à l’Université de Sherbrooke durant l’automne 2024.  
Ce projet est conçu comme une application full-stack combinant **Java**, **Vue.js** et **HTML**, avec des composants front-end et back-end intégrés.

**Code source:**  
[github.com/AlexandreAuclair/Beyond3.5](https://github.com/AlexandreAuclair/Beyond3.5)

---

## Résumé du projet

Beyond3.5 est une application que j’ai réalisée dans le cadre d’un cours à l’université.C'est un créateur de personnage pour le jeu donjon et dragon 3.5 qui s'inspire du site web Beyond qui utilise la 5e version du jeu. Comme la version 3.5 est la version la plus compliquée de D&D, nous voulions avoir un outil similaire à l'outil récent de Beyond.
Le code est structuré en deux parties principales :
- **Frontend** : une interface dynamique construite avec Vue.js et HTML
- **Backend** : logique serveur en Java

Ce projet m’a permis de renforcer mes compétences en développement web full-stack ainsi que dans l’intégration front-end/back-end.

---

## Technologies utilisées

- **Java** — serveur backend  
- **Vue.js** — frontend interactif  
- **HTML / CSS** — structure et styles  
- **Git & GitHub** — gestion de code et déploiement
