Ce projet est un **jeu vidéo fait sur Unreal Engine 5** qui mettait en partenariat **l'Université de Sherbrooke** et **l'École NAD-UQAC**.

L’objectif de ce projet était de concevoir un jeu vidéo destiné à être présenté à la compétition de jeux vidéo étudiants, les Rookie Awards, en 2025. Nous sommes fiers d’annoncer avoir remporté la deuxième place.

**Code source:**  
[github.com/AlexandreAuclair/2D_game_engine_with_c--_and_lua](https://github.com/AlexandreAuclair/2D_game_engine_with_c--_and_lua)

---

## Fonctionnalités
- Moteur Unreal engine 5.
- Utilisation des Nodes pour coder le jeu.
- Utilisation de script C++ pour certains codes.
- Coopération avec une équipe à distance dans une autre école.
- Apprendre comment gérer les conflits avec Perforce.

---

## Aperçu de l'architecture

Le moteur offre deux méthodes pour coder le jeu. La première consiste à exécuter du code C++ et à le compiler directement sur le moteur. La seconde
implique l’utilisation de « Nodes », qui sont de petites boîtes représentant des éléments de code et qui peuvent être connectées entre elles pour accomplir
les mêmes tâches que le code source textuel. Suite à la réalisation de ce projet, je suis personnellement convaincu que les «Nodes» sont particulièrement
complexes à comprendre et ralentissent le processus de développement du projet.

### Ce que j'ai fait dans le projet

Suite au lancement du projet, mon équipe, basée à Sherbrooke, a procédé à l’examen minutieux de tous les bogues nécessitant correction, compte tenu de l’état avancé du
projet.  Par la suite, nous avons entamé le codage des habilités du joueur ainsi que certaines fonctionnalités du jeu, telles que les points de contrôle.  Enfin, nous avons
consacré notre attention à l’intelligence artificielle des ennemis jusqu’à ce que la session soit terminée.
